# Floating Notes

Floating Notes is a modern, cross-platform note-taking application that combines the power of Electron with the flexibility of React and TypeScript. It provides a seamless experience for users who need to quickly capture and organize their thoughts.

## Features

### Modern UI/UX

- Clean and intuitive interface built with React and Tailwind CSS
- Responsive design that works across all platforms
- Dark mode support with One Dark theme
- Smooth animations and transitions

### Rich Text Editing

- Powered by MDX Editor for enhanced markdown support
- CodeMirror integration for code snippets
- Syntax highlighting
- Real-time preview

### Cross-Platform

- Available for Windows, macOS, and Linux
- Consistent experience across all platforms
- Native system integration

### Data Management

- Local storage using electron-store
- Automatic updates with electron-updater
- Data persistence and backup options

### Developer Experience

- Built with TypeScript for type safety
- Modern development tools and workflows
- Hot reloading during development
- Comprehensive build system

## Technical Stack

- **Frontend Framework**: React 18
- **Desktop Framework**: Electron
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State Management**: Recoil
- **UI Components**: Radix UI
- **Icons**: Lucide
- **Build Tool**: Vite
- **Package Manager**: npm/bun

## Getting Started

### Prerequisites

- Node.js (Latest LTS version)
- npm or bun package manager
